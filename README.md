# Dagu Recipes

Runnable, community-maintained workflows for [Dagu](https://github.com/dagucloud/dagu).

Each recipe is a single workflow that can be inspected, copied, and adapted without installing a plugin or framework. Catalog validation confirms that the metadata and Dagu YAML are structurally valid; it does not make contributed commands trustworthy. Review every workflow before running it.

Browse the catalog at [dagu.sh/recipes](https://dagu.sh/recipes).

## Contribute

- [Contribute a recipe](CONTRIBUTING.md)
- [Request a recipe](https://github.com/dagucloud/recipes/issues/new?template=recipe_request.yml)
- [Report a security concern](https://github.com/dagucloud/dagu/security)

Recipes are licensed under Apache-2.0 so they can be copied into private and commercial operations.
